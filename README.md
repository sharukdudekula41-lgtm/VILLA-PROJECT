# 🏡 Villa Project

## 📌 Overview
Villa Project is a modern and responsive real estate website designed to showcase luxury villas and premium properties. The application provides an attractive user interface where users can browse villas, explore property details, and contact the seller. It is built using modern frontend technologies to ensure a smooth and responsive user experience.

## ✨ Features
- 🏠 Responsive homepage with modern UI
- 🔍 Browse available villas
- 📄 Detailed property information
- 🖼️ High-quality property images
- 📱 Mobile-friendly design
- 📞 Contact section
- 📍 Location and property details
- 🎨 Clean and attractive layout

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
